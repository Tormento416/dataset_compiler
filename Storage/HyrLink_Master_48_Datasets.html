HyrLink

Master 48-Dataset Directory for Launch Features & Voice Pipeline

This directory provides 48 curated open-source datasets (6 datasets across each of HyrLink’s 8 baseline launch features). It expands training coverage for resume transformation, deep probing, skill scoring, role-fit matchmaking, candidate proxy chat, and natural voice interaction (TTS prosody alignment & STT disfluency cleanup).

II. Dataset Summaries & Use Cases

Feature 1: Resume Rewriting (Narrative Format)

1. callmeech / resume-score-details
Category: Narrative Resume Transformation
Summary: 1,031 paired resumes and JDs generated with GPT-4o containing rich micro/macro justification narratives.
Use Case: Teaches the SLM to convert dry experience bullets into persuasive narrative summaries.
2. WikiBio Dataset
Category: Tabular to Prose Synthesis
Summary: 728,321 Wikipedia infobox tables mapped directly to introductory narrative biographical paragraphs.
Use Case: Fine-tunes structured-data-to-narrative generation, preserving exact facts without dropping metrics.
3. ResumeAtlas
Category: Seniority Narrative Alignment
Summary: 13,389 resumes with multi-round human expert annotations mapped to experience tiers.
Use Case: Rewrites candidate bullet points into executive narrative stories matching target seniority.
4. skepss / resume-job-description-fit
Category: Resume Contextual Framing
Summary: Contextually paired resumes and job descriptions emphasizing career trajectory alignment.
Use Case: Teaches the SLM to frame a candidate's historical experience around the target role's narrative arc.
5. DatasetMaster Normalized Resumes
Category: Clean JSON Parsing
Summary: Clean JSON schema normalization of raw candidate resumes.
Use Case: Provides clean input schema structuring before sending extracted data into narrative generation prompts.
6. Saugataroyarghya / Resume Dataset
Category: Multi-discipline Summarization
Summary: 10,000 resumes across 25 career domains paired with candidate objectives.
Use Case: Expands domain-specific vocabulary for rewriting engineering, marketing, finance, and product resumes.

Feature 2: Candidate Deep Dives (Questionnaire & Probing)

7. AnthropicInterviewer
Category: Qualitative AI Probing
Summary: 1,250 qualitative, semi-structured interviews conducted by AI.
Use Case: Fine-tunes the SLM on how to ask deep follow-up questions based on unpolished candidate answers.
8. Inquisitive Question Generation
Category: Elicitative Questioning
Summary: 19,000 text spans paired with questions designed to evoke deeper explanations and underlying motivations.
Use Case: Generates targeted follow-up questions when a candidate provides brief or ambiguous answers.
9. CounselChat
Category: Reflective Listening
Summary: Counseling dialogues focusing on reflective active listening and underlying context extraction.
Use Case: Teaches HyrLink to uncover root candidate experiences and core achievements behind unpolished answers.
10. Comprehensive QA Benchmark
Category: Multi-turn QA Logic
Summary: 160k+ QA pairs combining CoQA and QuAC multi-turn conversational dialogs.
Use Case: Maintains contextual memory over multi-step questionnaire deep dives with candidates.
11. QASC (Sentence Composition)
Category: Fact Synthesis
Summary: Multi-fact reasoning dataset combining separate facts into unified explanations.
Use Case: Synthesizes multiple scattered candidate answers into one coherent career story.
12. MentalChat16K
Category: Behavioral Probing
Summary: 16,000 multi-turn behavioral dialogues focused on personal narrative extraction.
Use Case: Probes candidate soft skills, workplace challenge handling, and interpersonal style.

Feature 3: Skill Validation & Testing

13. SkillSpan
Category: Skill Extraction
Summary: ESCO-mapped hard/soft skill span annotations from job texts.
Use Case: Extracts granular skills from candidate claims to isolate what needs to be validated.
14. TechWolf Skill Extraction
Category: Technical Skill Boundaries
Summary: Sentence and span-level skill tags across technical job postings.
Use Case: Defines technical boundaries so HyrLink generates domain-accurate testing scenarios.
15. MBPP (Mostly Basic Python Problems)
Category: Entry/Mid Skill Validation
Summary: 974 programming problems with task descriptions, code solutions, and test cases.
Use Case: Evaluates entry-level technical candidate responses with automated test case validation.
16. OpenAI HumanEval
Category: Logic Validation
Summary: 164 hand-crafted coding problems with unit tests and docstrings.
Use Case: Generates dynamic live-coding scenario prompts and evaluates code correctness.
17. SWE-bench
Category: Complex System Validation
Summary: Real software engineering GitHub issues, code patches, and test suite executions.
Use Case: Validates senior technical claims by setting up realistic engineering problem-solving scenarios.
18. APPS Dataset
Category: Comprehensive Technical Testing
Summary: 10,000 coding problems ranging from introductory to competitive programming.
Use Case: Calibrates numeric skill validation scores based on problem difficulty tier.

Feature 4: Role-Fit Scoring

19. Candidate Job Role & Skill Gap Dataset
Category: Gap Analysis
Summary: Candidate profiles paired with target job roles and explicit skill gap annotations.
Use Case: Directly trains the SLM to output "What's Missing" reports and weighted gap scores.
20. AI Recruitment Pipeline Dataset
Category: Outcome-Calibrated Matching
Summary: Resume and screening data linked to actual final hiring decisions.
Use Case: Calibrates role-fit scoring models against real recruitment selection outcomes.
21. facehuggerapoorv / resume-jd-match
Category: Semantic Fit Rating
Summary: Paired resume and JD samples with semantic match scores.
Use Case: Fine-tunes overall profile alignment scoring logic.
22. netsol / resume-score-details
Category: Macro/Micro Weighting
Summary: Resumes scored against JDs with explicit macro (experience/strategy) and micro (skill) weighting.
Use Case: Teaches HyrLink to generate structured weighted scoring rubrics and justification paragraphs.
23. syncoraai / resume-screening-llm-training
Category: Synthetic Screening Instruction
Summary: Instruction dataset for candidate evaluation and ranking.
Use Case: Enhances instruction following for complex multi-criteria candidate screening prompts.
24. sonalshinde123 / ai-driven-resume-screening
Category: Multi-category Screening
Summary: Multi-category candidate screening dataset with explicit qualification badges.
Use Case: Improves hard skill and qualification check accuracy during scoring.

Feature 5: Pro Chatbot (AI Proxy of Candidate)

25. Persona-Chat
Category: Trait Grounding
Summary: Multi-turn dialogues where agents adhere strictly to assigned background facts and tone.
Use Case: Ensures the Pro Chatbot maintains candidate personality and career facts in recruiter interviews.
26. EmpatheticDialogues
Category: Emotional Alignment
Summary: 25k conversations grounded in emotional contexts.
Use Case: Infuses warmth, confidence, and natural emotional tone into candidate proxy responses.
27. DailyDialog
Category: Natural Dialogue Flow
Summary: High-quality multi-turn dialogues covering daily life and professional interactions.
Use Case: Fine-tunes conversational turn-taking, cadence, and backchanneling.
28. Blended Skill Talk
Category: Multi-skill Persona Switching
Summary: Dialogues combining persona adherence, knowledge sharing, and empathy.
Use Case: Enables the proxy chatbot to discuss technical skills while staying in candidate persona.
29. OpenAssistant / oasst1
Category: Human Instruction Following
Summary: Human-annotated conversational instruction dataset.
Use Case: Improves responsiveness to unexpected recruiter questions during AI proxy interviews.
30. Synthetic Persona Chat
Category: Extended Persona Consistency
Summary: Extended multi-turn dialogues featuring detailed character profiles.
Use Case: Prevents persona degradation during long recruiter chat sessions.

Feature 6: Recruiter Job Postings & Candidate Pairing

31. Candidate Recommendation Model Datasets
Category: Pool Matchmaking
Summary: Frameworks mapping recruiter job requisitions to candidate pools.
Use Case: Ranks candidate databases against new job postings and picks top choices.
32. Salient Entity Extraction Dataset
Category: Requisition Parsing
Summary: Labeled entity spans in job text (skills, domain, experience).
Use Case: Parses recruiter job postings into structured search queries.
33. Skill Scoring NLP Model Repository
Category: Candidate Ranking Logic
Summary: Semantic evaluation metrics for scoring candidate skills against job requirements.
Use Case: Drives comparative candidate selection rationales.
34. Resume Skills vs Interview Calls
Category: Call-back Probability Calibration
Summary: Resume feature sets correlated with actual interview invitation rates.
Use Case: Calibrates candidate pairing logic toward profiles most likely to get interview calls.
35. Skill-Evol-Bench
Category: Skill Taxonomy Mapping
Summary: Evolving skill benchmark mapping legacy skill names to modern tech stack equivalents.
Use Case: Matches candidate profiles with older skill phrasing to modern job descriptions.
36. amjad-awad / skill-extractor
Category: Rapid Skill Extraction
Summary: Lightweight skill extraction model and training corpus.
Use Case: Powers fast candidate filtering across large resume databases.

Feature 7: Voice Synthesization (TTS Alignment & Prosody)

37. DisfluencySpeech
Category: Conversational Paralanguage
Summary: Studio conversational English speech dataset with annotated non-speech events and pause markers.
Use Case: Inserts natural paralanguage markers (`[laughter]`, `[sigh]`, `[pause]`) into TTS text.
38. SeamlessExpressive / Expresso
Category: Pitch & Prosody Mapping
Summary: High-quality expressive speech annotated with pitch contours, speech rate, and emotion styles.
Use Case: Teaches the SLM to output SSML prosody tags to control downstream voice style.
39. LibriTTS-R
Category: Restored Clean Prosody
Summary: 585 hours of clean restored audio with normalized text and phonetic alignments.
Use Case: Fine-tunes phonetic spelling hints and text normalization for crisp pronunciation.
40. LJSpeech
Category: Single-Speaker Acoustic Baseline
Summary: 13,100 clean single-speaker audio clips with exact transcriptions.
Use Case: Provides acoustic baseline alignment for clean text-to-phoneme output generation.
41. CSTR VCTK Corpus
Category: Multi-accent Prosody
Summary: Speech recordings from 110 English speakers across diverse regional accents.
Use Case: Prepares the SLM to format text for diverse candidate voice clones and accents.
42. MELD (Multimodal Emotion Lines)
Category: Conversational Emotion Tags
Summary: Conversational dialogue audio tagged with emotion labels (joy, surprise, fear, neutral).
Use Case: Maps candidate conversational intent to explicit emotional tags for expressive TTS rendering.

Feature 8: Speech-to-Text (STT) Processing & Cleanup

43. ami-disfluency
Category: Spoken Disfluency Annotations
Summary: 35,000+ annotated disfluency segments (false starts, stutters, filler words) in meeting audio.
Use Case: Fine-tunes the SLM to clean unedited spoken transcriptions into clear text.
44. Switchboard Disfluency Transcripts
Category: Raw vs Clean Spoken Text
Summary: Conversational transcripts with explicit disfluency edit tags.
Use Case: Strips filler words ("um/uh", false starts) while preserving candidate core intent.
45. Transcription Cleanup Trainer
Category: Goldilocks Transcript Cleanup
Summary: Paired raw Whisper transcripts and manually cleaned ground-truth targets.
Use Case: Directly trains the SLM to transform raw ASR audio transcripts into polished sentences.
46. Auto Whisper Disfluency Dataset
Category: ASR Disfluency Reduction
Summary: Benchmark dataset paired for training ASR post-processing cleanup models.
Use Case: Cuts transcription artifacts and run-on sentences in spoken candidate answers.
47. VoxPopuli
Category: Spontaneous Speech Transcripts
Summary: Large-scale spontaneous speech transcripts with natural speech disfluencies.
Use Case: Improves SLM robustness against noisy, informal, or accented candidate audio transcriptions.
48. LibriSpeech ASR
Category: Acoustic Text Normalization
Summary: 1,000 hours of read speech with normalized vs unnormalized text transcriptions.
Use Case: Handles number expansion, acronym normalization, and punctuation restoration in raw STT text.
